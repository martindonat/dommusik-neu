# Eigene Bilder

Lege hier lizenzierte/eigene Fotos ab, z. B.:

- `chor.jpg`
- `orgel.jpg`
- `domsingschule.jpg`
- `verein.jpg`
- `team.jpg`

In `data/home.yaml` kannst du pro Slide optional ein Feld setzen:

```yaml
image: "/images/chor.jpg"
```

Die Templates unterstützen diesen optionalen Bildpfad. Ohne Foto wird eine reine CSS-Fläche als Platzhalter dargestellt.
